# N7 Board — Team Task Manager

An installable **Progressive Web App (PWA)** for NOSH7's internal team task and to-do management. Designed for the NOSH7 ops team to track work across users and categories.

## What It Does

A dashboard-style task management tool that gives the NOSH7 team a real-time view of all tasks — who owns what, what's upcoming, and how the team is performing — all accessible offline.

## Key Features

- **Stats dashboard** — key task metrics at a glance
- **By-user breakdown** — see every team member's task load
- **By-category breakdown** — organize tasks by type or department
- **Top Active / Upcoming / Avg Completion widgets** — team performance indicators
- **Activity feed** — live stream of recent task actions
- **Add / Edit task modals** — full task creation and editing flow
- **Activity log** — full history of changes
- **Settings panel** — configure preferences
- **Installable PWA** via `n7-sw.js` service worker — works offline, adds to home screen
- **Zero dependencies** — vanilla HTML/JS, no framework

## Tech Stack

- HTML, CSS, Vanilla JavaScript
- Service Worker (PWA, offline-capable)

## Audience

NOSH7 team members managing daily operations and task assignments.
